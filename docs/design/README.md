# Design documents

These documents own the gameplay design. Each rule lives in exactly one of them.
Recipes, numbers and stage assignments are proposed starting values until play testing confirms them.

| Document | Owns | Look here for |
|---|---|---|
| [VISION.md](VISION.md) | The fixed principles | What never changes |
| [PROGRESSION_MAP.md](PROGRESSION_MAP.md) | Player projects SR0 to SR9 and milestones M0 to M10 | What the player does at each stage; acceptance per milestone |
| [GUIDE_PROGRESSION_TREE.md](GUIDE_PROGRESSION_TREE.md) | Guide pages, advancements and their prerequisites | Achievements; the genetic atlas of species and mobs (section 15); tools and weapons (section 17) |
| [BLOCK_CATALOG.md](BLOCK_CATALOG.md) | Every organ, structure and construction block, by tier | Machines, multiblocks, helpers and nurseries |
| [ITEM_CATALOG.md](ITEM_CATALOG.md) | Every item, ingredient and preparation recipe | Tools, samples, grafts, food, backpack, ore recovery |
| [ARMOR_EVOLUTION.md](ARMOR_EVOLUTION.md) | The four armor pieces, their branches, fuel and recovery | Armor |
| [LIVING_SUBSTRATE_MUTATIONS.md](LIVING_SUBSTRATE_MUTATIONS.md) | Substrate growth, function, reinforcement | Ground cells; diagram in `diagrams/` |
| [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md) | Product questions only the owner can answer | Currently empty |
