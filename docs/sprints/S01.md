# Sprint S01: the feedback loop

Milestone: M1. Status: draft, owner review pending.

Goal: Spore Culture and Living Substrate are in the game with recipes and guide pages, and every story is proven by tests and real-game screenshots that an agent reads without a human.

Acceptance (ROADMAP.md): Spore Culture converts eligible exposed ground and bone meal matures it, in GameTests; recipes and guide pages exist; client captures of all three stages, front, back and inventory scale, pass the capture checks and are read by the reviewer; the owner repeats it by hand in a fresh world.

This sprint is the pilot. The planner does IF-001 and IF-002 as the examples to copy. Sonnet does the rest, one story per run. The sprint is done only when ART-001 in ART.md is accepted too: placeholders never reach the owner's build. Rules: [AGENTS.md](../../AGENTS.md). Template and loop: [ENGINEERING.md](../../ENGINEERING.md#stories-and-sprints).

Shared facts for every story here:

- Ids: `infestusfrontier:spore_culture` (item), `infestusfrontier:living_substrate` (block and block item). Block state property `stage`: `basic`, `young`, `mature`.
- Java: mod package `org.jd.infestusfrontier.ecology`, public class `EcologyModule` with `DeferredBlock<LivingSubstrateBlock> LIVING_SUBSTRATE`, `DeferredItem<BlockItem> LIVING_SUBSTRATE_ITEM`, `DeferredItem<Item> SPORE_CULTURE`. `LivingSubstrateBlock.STAGE` is `EnumProperty<SubstrateStage>`; `SubstrateStage` is an enum in the same package with `next()` returning `Optional<SubstrateStage>`.
- Eligible ground is the block tag `infestusfrontier:substrate_hosts`: dirt, grass_block, coarse_dirt, podzol, rooted_dirt, mycelium, mud, stone, deepslate, andesite, diorite, granite, tuff.
- Exposed means the block on the clicked face has an empty collision shape (air, grass, flowers, snow layer count as exposed; stone above does not).
- GameTest classes live in `src/testMod/java/org/jd/infestusfrontier/testmod/`, one class per owner, template `infestusfrontier_tests:empty` (16x12x16 of air; relative y=0 is the lowest template layer, so a block set at (1,1,1) floats, which is fine). Mock players from `makeMockPlayer` need `getAbilities().instabuild = true` to count as creative for items; `EcologyTests.holding` does that. Flat capture world: surface block at y=-61, the player stands at y=-60.
- Demo world: `src/testMod/resources/captures/demo.json` (ENGINEERING.md, section Demo world). Row A (z=-36, signs z=-37) taken x: 0, 2, 4 substrate stages; 12 crafting table and 14 chest (IF-003); 16 lectern (IF-006); 20 Digestive Sac and 22 Biomass Bladder (S02). Row B (z=-33 to -31) holds the host plots at x=-6 to 8. Row C (z=-29 to -26, signs z=-30) is for IF-008. The player starts at (2.5, -60, -39.5) facing south.
