# V3 prototype records

These files describe experiments made in the `InfestusFrontierModV3` prototype repository.
They are evidence about what worked and what did not. They are not specification.
The design documents in [../design/](../design/README.md) decide what we build.

| Document | Experiment |
|---|---|
| [LIVING_COLONY_DIRECTION.md](LIVING_COLONY_DIRECTION.md) | Visual rule: anatomy explains function. Veins, drones, chunk loading proposals |
| [BIOLOGY_LAB.md](BIOLOGY_LAB.md) | Substrate stages, DNA extractor, expandable reservoir |
| [COLONY_LAB.md](COLONY_LAB.md) | Symbiotic armor, vascular lift, tissue transport, helpers, biomass loop |
| [VASCULAR_JUNCTION.md](VASCULAR_JUNCTION.md) | Growable junction with reservoir on top |
| [LOGISTICS_CONSOLE.md](LOGISTICS_CONSOLE.md) | Probe and console for veins and junctions |
| [LOGISTICS_VALIDATION.md](LOGISTICS_VALIDATION.md) | Defects found and fixed in the transport loop |
| [MINING_ORGANS.md](MINING_ORGANS.md) | Three horizontal excavation multiblocks |
| [DOWNWARD_MINING.md](DOWNWARD_MINING.md) | Descending cradle, rootstock, crucible, leaching nodule |
| [EXCAVATION_SHOWCASE.md](EXCAVATION_SHOWCASE.md) | Manual leaching, stair excavation, deep strip |
| [BURROWING.md](BURROWING.md) | Temporary passage through rock with a grafted suit |
| [UI_ARCHITECTURE.md](UI_ARCHITECTURE.md) | Decision to use native container menus and screens |
| [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md), [PERFORMANCE.md](PERFORMANCE.md), [TESTING.md](TESTING.md) | The prototype's engineering rules. Superseded by [../process/](../process/ARCHITECTURE.md) |
| [ART_PROVENANCE.md](ART_PROVENANCE.md), `art/` | Prompts and provenance of generated textures. Source PNGs stay in the V3 repository under `art/` |
