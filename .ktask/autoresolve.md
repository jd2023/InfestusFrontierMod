Read the failed checks, verification log and .ktask/logs/review.md when present.
Diagnose, implement the correction, run affected tests, commit and push the repair.
Preserve the original task baseline and review the complete task, not just the
latest repair. Necessary prerequisite, harness, test and configuration fixes are
part of this task. Do not repeat an unchanged failure or request file permissions.

work. Write the native report even if the attempt fails. Human input is reserved
for product decisions and external authority; ktask owns retries and advancement.
