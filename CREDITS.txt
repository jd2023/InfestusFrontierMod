Infestus Frontier original assets

Every shipped texture, model, sound and name is original work made for this
project. Add one line per asset family here: what it is, who made it, with what
tool, on what date. No vanilla, prototype or third-party art is copied.

Spore Culture (src/main/resources/assets/infestusfrontier/textures/item/spore_culture.png, 32x32 RGBA): original artwork generated for this project with OpenAI's built-in image generation tool, 2026-10-16; CC BY 4.0. Export: python3 scripts/texture.py <source.png> src/main/resources/assets/infestusfrontier/textures/item/spore_culture.png --size 32 --colors 0.
Living Substrate mature (art/living_substrate_master.png, 256x256): original artwork generated for this project with OpenAI's built-in image generation tool, 2026-10-15; CC BY 4.0. V3 substrate and Astra evaluation tissue were style references. The young and basic stages are derived from that master by art/gen_substrate_stages.py (planner, 2026-10-17), so the three stages share one vein network; the generator writes all 48 tiles, wired to the block by position.
Synaptic Probe (textures/item/synaptic_probe.png, 32x32 RGBA): original artwork generated for this project with OpenAI's built-in image generation tool, 2026-10-16; CC BY 4.0. Exported with scripts/texture.py --size 32 --colors 0.
Biomass fluid (textures/block/biomass_still.png, biomass_flow.png, item/biomass_bucket.png overlay on vanilla's bucket sprite), organ GUI sheet (textures/gui/organ.png), Digestive Sac, Biomass Bladder and Culture Bowl models, animations and model textures (geo/, animations/, textures/block_entity/) and the Organ Bud static model (models/block/organ_bud.json, textures/block/organ_bud.png): original work from the planner's Python generators under art/, 2026-10-16 and 2026-10-17. The Membrane Rack model (art/gen_membrane_rack.py) the same way, 2026-10-19.
Membrane Sheet icon (textures/item/membrane_sheet.png): a placeholder drawn by the planner's script on 2026-10-19 until ART-004 ships the final icon.
The Waking Genome cover (textures/item/the_waking_genome.png, 32x32 RGBA) and nine Contact entry illustrations (textures/book/*.png, 200x200 RGBA canvases with roughly 200x100 artwork): original artwork generated for this project with OpenAI's built-in image generation tool, 2026-10-18; CC BY 4.0. Prompts and export settings: docs/sprints/ART.md, ART-003. Existing organ screenshots, item icons and the living-substrate master supplied shape and material references.
