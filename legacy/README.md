# Historical reference

`forge-1.19.2` preserves the previous main-branch project from `772c5cb` without
source or asset edits. It is not included in the root Gradle build or production
JAR. Its own wrapper/configuration remain for historical use; the new foundation
does not claim that this older build works with current tooling.

Root `LICENSE.txt`, `CREDITS.txt` and Git history are preserved. No old assets or
gameplay have been promoted into the new production source set. Do not run an
archived build against personal or prototype saves as part of a new-project gate.
